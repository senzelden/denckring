# denckring-de-data

German lexicon data for denckring: word membership and a noun list, derived
from Wikidata Lexemes and vendored as CC0-licensed, gzipped text files. See
`LICENSE-WIKIDATA` for provenance.

Membership is casefolded, which deliberately merges ß and ss spellings (e.g.
Maßen/Massen); the noun list is not casefolded and keeps ß intact.
