      • Language packs
      • 1. English API, multilingual content
      • 2. `check` mandatory, `apply` optional
      • 3. Catalogue in YAML, not SQLite
      • 4. Language packs as capability-declaring plugins
      • 5. Continuous `score`, not a boolean
      • 6. Dual licence: MIT code, CC BY catalogue
      • 7. One module per procedure
      • 8. The catalogue lives inside the package
      • 9. Diacritic folding is a parameter, not a policy
      • 10. Language packs are discovered through an entry-point group
      • 11. Checkability is a property of the procedure, not of its capabilities
      • 12. Two syllable capabilities, with the weaker one as the floor
      • 13. Linguistic data ships as separate distributions
      • 14. Metre is a satisfiability question, not a comparison
      • 15. One capability per question the lexicon is asked
      • 16. One data pack per language, and a collision is an error
      • 17. A device's own data ships with its procedure
      • 18. Whether the author stated the rule is its own field
      • 19. Figures are alphabets read at several levels
      • 20. A corpus is supplied by the reader, never by the package
      • 21. Implement the transferable part, not the artefact
      • 22. German is a built-in default, not an entry point
      • 23. The German lexicon is Wikidata Lexemes
      • 24. Apache-2.0 for the code
      • 25. `apply` gets the spine `check` has
      • 26. `_produce -> list[str]` is the primitive; `apply` returns its first result
      • 27. `_produce` returns `Produced`, so a candidate can carry its score
      • 28. A word list graded by commonness, because a membership oracle cannot rank
      • 29. Where the catalogue already offered a choice, the parameter now exists
      • 30. German pronunciations come from Wiktionary
      • 31. A device is an address space
      • 32. The French lexicon
      • 33. The catalogue has two layers
      • 34. French verse is counted a line at a time
      • 35. A letter has two readings, and `requires` says which
      • 36. A leading proclitic is not a noun
      • 37. The calculator word
      • 38. German frequency, and a source whose case survives
