    Sentence length constraint¶

    sentence_length_constraint · syntax · validated

    A text whose sentences must each fall within a prescribed number of words, exactly or as a bound.

    Provenance¶

    • Source: Traditional; standard in style manuals and readability work
    • Attribution: traditional — classical or folk; no single origin to name
    • Checkability: self — decidable from the text and its parameters alone
    • Attested: codified — formulated as a rule by a tradition rather than declared by an author

    Details¶

    • Kind: restrictive
    • Languages: en
    • Requires: tokens
    • Deterministic: yes

    Prompt hint¶

    Write so that every sentence contains exactly the given number of words.

    Parameters¶

    Name Type Default Description
    tolerance integer 0 Permitted departure in either direction.
    words integer — Words each sentence must contain.

    Examples¶

    three-word-sentences¶

    en — this text satisfies the procedure.

    one two three. four five six.

    Parameters: words=3
